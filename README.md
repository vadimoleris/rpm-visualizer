# Обороты — визуализатор частоты вращения (PWA)

Точка-болид на круге. Основной режим — **80 об/мин**: оптимальный темп кручения
ручки аварийного генератора. Универсальный диапазон 1–12000 об/мин с честным
замедлением выше порога восприятия. Офлайн, без зависимостей.

## Возможности
- 80 об/мин по умолчанию, выделенный пресет «⚡ генератор»; звук-метроном на каждый оборот (по желанию)
- пресеты: 60 (стрелка часов), 1000 (холостые), 3000, 6000 (отсечка авто), 12000 (спортбайк)
- логарифмический слайдер + степперы (±1, удержание ускоряется; Shift+стрелки ±10, PgUp/PgDn ±100)
- счётчик оборотов и времени сессии, сброс; тап по циферблату или пробел — пауза
- хвост болида растёт со скоростью; смена частоты без скачка фазы (rAF-аккумулятор)
- тёмная приборная тема — намеренно, для максимального контраста точки

## Физика восприятия (задача «со звёздочкой»)
Код считает любую частоту; предел — развёртка экрана и глаз.
- плавно: ≳10 кадров/оборот → ~360 об/мин при 60 Гц (~720 при 120 Гц); приложение измеряет реальную частоту кадров
- направление читается до ~1800 об/мин (Найквист, 2 кадра/оборот)
- выше — стробоскоп: 6000 об/мин на 60 Гц выглядит как 1200 назад, 12000 — как 1200 вперёд
- поэтому выше порога включается автозамедление ×2…×200 (бейдж на циферблате), число всегда реальное
- чекбокс «1:1» в разделе «Физика восприятия» — показать стробоскоп своими глазами
- глаз сливает мелькание выше ~20–30 Гц, так что 100–200 об/с он не различает в принципе

Вывод: для 1000–12000 использовать можно как масштабированный тахометр-демо, не как буквальное движение.
